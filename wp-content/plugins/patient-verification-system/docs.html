Modernlisim Plugin Documentation

Plugin Overview

The Medical Patient Verification Plugin by Modernlisim is a WordPress solution designed to manage and verify patient records. It provides functionalities for:

  • Adding and managing patient records.
  • Frontend verification via a unique code.
  • Backend management for viewing and deleting records.

Installation Guide

  1. Download the plugin ZIP file from the provided source.
  2. Log in to your WordPress admin dashboard.
  3. Navigate to Plugins > Add New.
  4. Click the Upload Plugin button at the top of the page.
  5. Choose the downloaded ZIP file and click Install Now.
  6. Once installed, click Activate Plugin to enable it on your website.
  7. After activation, access the plugin from the Patient Verification menu in the admin dashboard.

Note: Ensure your server runs PHP version 8.0 and WordPress version 6.7.1 or higher for optimal performance.

Features

  • Unique 7-digit verification code generation.
  • Shortcode for embedding a verification form.
  • AJAX-based form submission for smooth user experience.
  • Real-time error handling with user-friendly feedback.
  • Customizable design via CSS for seamless website integration.

Shortcode

Use the shortcode below to display the verification form on any WordPress page or post:

[patient_verification]

This shortcode renders a user-friendly form with fields for entering the verification code.

Shortcode Attributes

  • placeholder_text: Custom placeholder text for the input field.
  • button_text: Custom text for the submit button.

Example:

[patient_verification placeholder_text="Enter Code" button_text="Verify"]

Admin Menu

Menu Items

  • Patient Verification: Add new patient records.
  • View Records: View and delete existing patient records.

The admin menu provides an intuitive interface for managing patient data and monitoring verification attempts.

Technical Details

Database Structure

The plugin uses a custom table:

{prefix}_patient_verifications

Fields:

  • id: Auto-incremented primary key.
  • patient_name: Name of the patient.
  • doctor_name: Name of the doctor.
  • verification_code: Unique code for verification.
  • expiry_date: Expiry date for the code.
  • is_expired: Boolean indicating whether the code is expired.

AJAX Workflow

The plugin uses AJAX for seamless frontend interaction:

  • Form submission triggers an AJAX request.
  • Verification logic runs in the backend.
  • Results are returned to the user without page refresh.

Customization

Styling

The plugin's styles can be customized by overriding the CSS classes in your theme:

  • .ver-code: Input field for the verification code.
  • .ver-output-error: Error message container.
  • .ver-out-success: Success message container.

Example:

.ver-code { border: 2px solid #ef233c; padding: 10px; font-size: 16px; }

Troubleshooting

  • Ensure the plugin is installed and activated.
  • Verify the database table `{prefix}_patient_verifications` exists.
  • Check AJAX URL configurations if the form does not work.
  • Test shortcode placement in a WordPress post or page.
  • Review console logs for potential JavaScript errors.
